# Cake Sort — Кондитерская

3D-головоломка на Three.js по механике «Cake Sort 3D — Color Puzzle»:
внизу очередь из трёх тарелок с кусочками тортов. Перетащите тарелку
на свободную ячейку поля — игра сама проверит четырёх ортогональных
соседей и автоматически перебросит совпадающие кусочки. Шесть одинаковых
сегментов на тарелке складываются в целый торт: он надевает корону,
улетает на золотую подставку, а ячейка освобождается.

Кусочки игрок вручную не переносит; тарелки на поле после размещения
неподвижны (ТЗ п. 0.1–0.2).

## Возможности

- **8 фиксированных уровней** — поле от 2×3 до 3×4, от 2 до 6 видов
  тортов; после последнего уровня — циклический повтор. Данные уровней
  зашиты в `src/puzzle/game/levels.ts`, никакой случайной генерации.
- **Гарантия проходимости** — DFS-солвер с мемоизацией и «жадной»
  эвристикой проверяет каждый уровень и используется для подсказки.
- **Детерминированная автосортировка** — получатель кусочков и порядок
  обработки пар фиксированы правилами (ТЗ 5.4–5.6): одинаковый ход
  всегда даёт одинаковый результат.
- **Монеты и подсказка** — +10 🪙 за пройденный уровень; кнопка 💡
  (−15 🪙) подсвечивает золотыми кольцами тарелку очереди и ячейку.
- **Сохранение прогресса** — уровень и монеты в localStorage.
- Мышь и touch (Pointer Events), английская блокировка прокрутки
  страницы во время перетаскивания.

## Запуск

```bash
npm install
npm run dev        # дев-сервер: http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build      # tsc + vite build → dist/
npm run preview    # локальный сервер поверх dist/
```

В `dist/` лежит собранная версия — её можно открыть любым статичным
сервером (ES-модули не работают с `file://`, нужен http).

## Управление

Нажмите на тарелку в нижней очереди и, не отпуская кнопку, тащите её
на поле. Свободная ячейка подсвечивается золотым кольцом. Отпустите
над ячейкой — тарелка встанет, запустится автосортировка. Отпустите
мимо поля — тарелка плавно вернётся в очередь, ход не расходуется.
Пока идут переносы и сборка тортов, ввод заблокирован.

Победа — разместить все тарелки очереди и собрать все торты.
Поражение — поле заполнено, а очередь не пуста, либо очередь
закончилась, а на поле остались кусочки.

## Архитектура (4 слоя, ТЗ п. 9)

```
index.html                    — страница игры (HUD, оверлеи, тосты)
puzzle.html                   — старый адрес, редирект на index.html
src/puzzle/game/types.ts      — слой 1: данные (GState, LevelData)
src/puzzle/game/rules.ts      — слой 2: правила (соседи, SortResolver,
                                завершение тортов, конец партии) —
                                чистый TS, без Three.js/GSAP
src/puzzle/game/levels.ts     — слой 2: фиксированные уровни + солвер
src/puzzle/engine.ts          — слои 3–4: Three.js-сцена, drag&drop,
                                GSAP-анимации, оркестрация хода
src/puzzle/cakes.ts           — 3D-модели тортов, тарелок, стола,
                                подставки, короны
src/puzzle/sfx.ts             — WebAudio-синтезатор звуков
src/puzzle/main.ts            — точка входа: HUD, оверлеи, монеты
```

Игровые правила не зависят от Three.js и GSAP: слой `game/` тестируется
в Node (сценарии A–J из ТЗ п. 12: простое совпадение, завершение торта,
разные вкусы, диагональ, вместимость, детерминизм, потери).

## Технологии

Vite + TypeScript (strict) + Three.js + GSAP. Никакого физического
движка: перемещения тарелок и кусочков — лёгкие твины.
