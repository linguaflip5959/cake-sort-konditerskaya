# Cake Sort — Кондитерская

3D-головоломка на Three.js по механике «Cake Sort 3D — Color Puzzle»:
внизу очередь из тарелок с кусочками тортов. Перетащите тарелку
на свободную ячейку поля — игра сама проверит четырёх ортогональных
соседей и автоматически перебросит совпадающие кусочки. Шесть одинаковых
сегментов на тарелке складываются в целый торт: он надевает корону,
улетает на золотую подставку, а ячейка освобождается.

Кусочки игрок вручную не переносит; тарелки на поле после размещения
неподвижны (ТЗ п. 0.1–0.2).

## Возможности

- **Обучающие уровни 1–3 заданы вручную** (2×3, 2×3, 3×3): базовая
  механика, освобождение ячеек, двойная тарелка. С уровня 4 уровни
  **генерируются детерминированно** по номеру (seed = f(номер)): один и
  тот же уровень одинаков у всех и после перезапуска.
- **Кривая сложности**: поле растёт 3×3 → 3×4, вкусы 3 → 7, очередь
  5 → 10 элементов, двойные тарелки 0 → 2. Средняя длина решения
  растёт с номером уровня.
- **Гарантия проходимости**: генератор собирает уровни «обратной
  сборкой» от готовых тортов, каждый уровень проверяется DFS-солвером
  и порогом «случайной игры» (полностью случайные партии почти всегда
  проигрывают).
- **Двойная тарелка** (с уровня 3): две тарелки, жёстко соединённые
  золотой перемычкой. Берётся и ставится только целиком на две соседние
  свободные ячейки; кнопка «Повернуть двойную тарелку» (или клавиша R)
  вращает её на 90° — до и во время перетаскивания, хода не тратит.
  После размещения половинки живут как независимые тарелки, перемычка
  растворяется.
- **Монеты и подсказка** — +10 за уровень, «Подсказка −15» подсвечивает
  элемент очереди, целевые ячейки и показывает двойную в нужной
  ориентации. Прогресс и монеты — в localStorage.
- Мышь и touch (Pointer Events), блокировка прокрутки страницы.

## Запуск

```bash
npm install
npm run dev        # дев-сервер: http://localhost:5173
```

Продакшен-сборка и тесты:

```bash
npm run build      # tsc + vite build → dist/
npm run preview    # локальный сервер поверх dist/
npm test           # автотесты игрового слоя (scripts/pz-tests.ts)
```

Автотесты не требуют браузера: проверяют кратность 6 кусочков на
уровнях 1–100, решаемость солвером, детерминизм генератора (включая
запуск в отдельных процессах), долю побед случайной игры, поведение
двойной тарелки, правила сортировки и конец партии.

## Управление

Нажмите на тарелку в нижней очереди и, не отпуская кнопку, тащите её
на поле. Свободная ячейка подсвечивается золотым кольцом (для двойной —
оба кольца пары). Отпустите над ячейкой — тарелка встанет, запустится
автосортировка. Отпустите мимо поля — тарелка вернётся в очередь, ход
не расходуется.

Кнопки: «Подсказка −15», «Заново» и «Повернуть двойную тарелку»
(появляется, только когда двойная видна в очереди; на ПК также R).
Пока идут переносы и сборка тортов, ввод заблокирован.

Победа — разместить всю очередь и собрать все торты. Поражение — поле
заполнено (в том числе когда в видимом окне только двойные, а свободные
ячейки не образуют соседних пар), либо очередь закончилась с остатком.

## Архитектура (4 слоя, ТЗ п. 9)

```
index.html                     — страница игры (HUD, оверлеи, тосты)
src/puzzle/game/types.ts       — слой 1: данные (GState, TrayItem,
                                 ориентации двойной тарелки)
src/puzzle/game/rules.ts       — слой 2: правила (соседи, сортировка,
                                 размещения Move/legalMoves, конец
                                 партии) — чистый TS, без Three.js/GSAP
src/puzzle/game/fixed.ts       — слой 2: обучающие уровни 1–3
src/puzzle/game/generator.ts   — слой 2: детерминированный генератор
                                 уровней 4+ (обратная сборка + солвер
                                 + порог случайной игры)
src/puzzle/game/solver.ts      — слой 2: DFS-солвер с мемоизацией
src/puzzle/game/levels.ts      — слой 2: getLevel (фиксированные или
                                 генерация) и реэкспорт солвера
src/puzzle/engine.ts           — слои 3–4: Three.js-сцена, drag&drop,
                                 двойная тарелка (поворот, разделение),
                                 GSAP-анимации, оркестрация хода
src/puzzle/cakes.ts            — 3D-модели тортов, тарелок, стола,
                                 подставки, короны, перемычки
src/puzzle/sfx.ts              — WebAudio-синтезатор звуков
src/puzzle/main.ts             — точка входа: HUD, кнопки, монеты,
                                 туториал уровня 3
scripts/pz-tests.ts            — автотесты игрового слоя (npm test)
```

Игровые правила не зависят от Three.js и GSAP: слой `game/` тестируется
в Node (кратность, решаемость, детерминизм, качество рандома, двойная
тарелка, сортировка, конец партии).

## Технологии

Vite + TypeScript (strict) + Three.js + GSAP; тесты — tsx. Никакого
физического движка: перемещения тарелок и кусочков — лёгкие твины.
